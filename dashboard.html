추천은 총 RAM을 기준으로 정한 시작점입니다. 모델은 하나만 사용하며, 모든 구성은 순차 실행합니다.

02 · 팀원과 역할

이름과 담당 업무를 정해주세요

실행 흐름과 추가 설정

각 실행 단계에는 담당자가 필요합니다. 같은 역할의 팀원이 여러 명이면 작업별로 배분합니다. 설정 변경은 새 작업부터 적용됩니다.

현재 진행 중인 작업의 팀 구성은 유지됩니다.

EXECUTION PROFILE

어디에서 작업할까요?

사양과 현재 여유 메모리로 시작 구성을 추천합니다. 선호 환경 저장은 VM 설치나 연결을 실행하지 않습니다. 새 작업에서 저장한 실행 환경을 선택해 적용하세요.

VirtualBox 준비 · 선택 사항

Windows·Linux x64용입니다. VM 파일만 준비하며 OS 설치·부팅·작업 연결은 아직 별도입니다. macOS·ARM은 이 경로에서 지원하지 않습니다.

공식 체크섬 대조 · 선택

OS 자동 설치 파일 준비

꺼진 소유 VM에 설치 설정만 적용합니다. 부팅하지 않습니다. VM 전용 새 비밀번호를 사용하고 로그인용으로 보관하세요. 설치 보조 파일은 보호 폴더에 보관되며 일반 백업에 포함하지 않습니다.

중단된 준비 복구

VM 등록과 전용 폴더가 모두 없을 때만 준비 기록을 정리합니다. 앱은 VM이나 파일을 삭제하지 않습니다.

복원한 대기 항목 확인
연결을 켜도 아래 항목은 자동 처리하지 않습니다. 재개한 지시는 새 작업이나 제어 명령으로 처리될 수 있고, 알림은 Slack에 전송될 수 있습니다. 제외하면 기록은 남기고 처리하지 않습니다.
토큰은 이 Windows 사용자 계정으로 암호화해 저장합니다. 연결 확인은 인증과 권한만 검사하며 메시지를 보내지 않습니다. 연결을 켜면 지시와 작업 보고가 Slack을 거칩니다.
