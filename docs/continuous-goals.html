목표를 맡기고, 아침에 검토하세요.

리더가 다음 업무를 정하고 담당자에게 맡깁니다. 기존 실제 실행·팀원 검증·리더 반복 검토를 거친 결과는 검토함에 남고, 다음 업무를 이어갑니다.

1. 목표 등록

왼쪽 지속 목표에서 목적과 완료 조건을 적고 실행 시간·최대 작업 수를 지정하세요. 프롬프트에서 /goal 목표 내용으로 보내면 24시간·최대 20개 업무로 등록됩니다.

예: “사용 안내를 정리하고, 설치·실행·오류 해결 문서를 각각 작성해 실제 내용과 대조해 주세요.”

2. 자동 진행

한 번에 하나씩 실행합니다. 완료한 업무와 검증 근거를 다음 계획에 반영하며 같은 지시의 반복을 차단합니다. 실행 시간이나 작업 수가 끝나면 새 업무를 만들지 않습니다. 일시적인 모델 연결 오류는 대기 후 최대 3회 시도합니다. 작업 실패 3회 또는 계획 오류가 발생하면 사유를 남기고 멈춥니다.

일시 중지·종료는 다음 업무 생성을 멈춥니다. 이미 전달된 업무는 계속 진행될 수 있으며, 개별 작업 창에서 취소할 수 있습니다. 모아를 재시작해도 목표·접수 기록·검토 내용은 저장됩니다. 안전하게 재개할 수 있는 단계는 이어서 실행하며, VM 입력 중 종료되어 결과가 불명확한 단계는 확인 필요로 남깁니다.

3. 결과 검토

결과·로그 보기에서 파일·미리보기·실행 근거를 확인하세요. 소요 시간과 리더 검토·반려 횟수도 함께 표시됩니다. 확인·승인은 결과를 확인했다는 기록이며, Git 병합·배포를 실행하지 않습니다.

수정 요청에 바꿀 부분을 적으면 검증된 원본 파일을 보존·복사한 새 수정 업무로 등록됩니다. 한도나 실행 시간이 끝났다면 요청 내용만 보관되므로 새 목표가 필요합니다.

실행 전에 확인하세요

PC와 모아가 켜져 있어야 합니다. 활성 목표를 실행하는 동안 자동 절전을 방지하며 화면 꺼짐은 허용합니다. 직접 절전·종료하면 작업은 멈춥니다. 전체 업무가 일시 중지되어 있다면 상단에서 재개하세요. Windows VM은 설치와 명령 연결 확인을 완료한 업무용 환경이어야 합니다.

인증·라이선스 동의가 필요한 단계는 자동 완료되지 않습니다. 지속 목표 작업의 자동 Git 게시를 보류하며, 외부 배포·병합은 별도로 확인하세요. 24시간 무중단 실행을 검증했다는 뜻은 아닙니다.
