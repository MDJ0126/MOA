처음 시작하기

설명만 입력하고 첫 작업을 맡겨보세요.

  1. .\Start.ps1 -Demo를 실행하고 체험 화면 열기를 누르세요.
  2. 팀 설정에서 추천 구성을 저장하세요.
  3. 할 일을 적고 팀에 맡기기를 누르세요. 완료되면 작업을 열어 담당자별 대화와 결과물 ZIP을 확인하세요.

데모는 샘플 결과로 흐름을 확인하는 체험입니다. 실제 AI 업무를 시작하려면 아래 설치 안내를 펼쳐 주세요.

설치·실행 명령

모아는 내 PC에서 모델 하나를 공유하는 에이전트 팀입니다. 일을 맡기면 계획·개발·검증을 순서대로 진행하고 결과물을 정리합니다.

먼저 팀 구성만 저장하세요.

Slack과 VM은 필요할 때 준비하셔도 됩니다.

1. 설치 준비

현재 배포는 Windows x64용 프로젝트 폴더 형태입니다. Python 3.11 이상이 필요합니다. 설치·시작 스크립트는 MOA_PYTHON에 지정한 실행 파일을 우선 사용합니다. 지정하지 않았다면 PATH의 Python, 기존 Codex 번들 순서로 Python 3.11 이상과 sqlite3·ssl을 확인합니다.

Python이 없다면 공식 Python 다운로드에서 설치하세요. 이 앱은 Python이나 Windows 설정을 몰래 변경하지 않습니다.

모델 없이 먼저 체험하기

Python을 준비했다면 모델·VM을 설치하기 전에 .\Start.ps1 -Demo로 팀 설정과 순차 데모 흐름을 체험할 수 있습니다. 주소는 http://127.0.0.1:8767이며, 종료는 .\Stop.ps1 -Port 8767입니다. 실제 AI 추론·VM·Slack 연결은 차단하며 운영 data와 분리된 data-demo에 기록합니다. PowerShell 스크립트를 실행할 수 없으면 python src/app.py --demo를 사용할 수 있습니다.

데모는 지정된 샘플 결과를 생성하는 흐름 체험입니다. 요청한 프로그램을 실제 AI로 구현·검증한 결과가 아닙니다. 실제 업무를 시작하려면 아래 설치를 진행하고 일반 Start.ps1로 실행하세요. 데모 기록은 운영 작업에 자동 합치지 않습니다.

2. 연결 도구와 모델 준비

앱 폴더에서 PowerShell을 열고 아래 명령을 실행합니다. 이미 모델이 설치되어 있으면 -DownloadModel은 생략해도 됩니다.

.\Install.ps1 -DownloadModel

공식 Qwen 모델 약 4.68GB와 실행 도구를 내려받습니다. 네트워크에 따라 시간이 걸리며 파일 해시를 확인한 뒤 사용합니다. Slack 연결 도구는 이 폴더 안에 설치됩니다.

3. 실행

.\Start.ps1

브라우저에서 http://127.0.0.1:8765를 여세요. 모델과 작업 관리자를 함께 실행하고 비정상 종료를 감시합니다.

4. 추천 팀 저장

팀 설정 → 에이전트 팀에서 ‘이 PC 추천’ 구성을 선택하고 팀 구성을 저장하세요. 이름과 역할은 나중에 바꿀 수 있습니다. 모든 프리셋은 한 번에 하나씩 실행합니다.

5. 첫 작업 맡기기

워크스페이스의 입력창에 원하는 결과와 완료 조건을 함께 적습니다.

health.py에 체력을 0~100으로 제한하는 함수를 만들어 주세요.
음수는 0, 100보다 큰 값은 100이 되어야 합니다.
test_health.py에 경계값 테스트도 추가해 주세요.

진행 상황은 ‘작업과 대화’에서 확인하고, 완료 후 보고서와 결과물 ZIP을 받으세요. 데모 모드는 AI를 사용하지 않는 흐름 점검용입니다.

포트 충돌과 이 프로젝트의 종료

일반 시작은 8765·8766 포트를 먼저 확인하고 다른 앱을 자동 재사용하지 않습니다. 포트를 열 수 없으면 기존 앱을 해당 프로젝트에서 종료하거나 직접 실행의 다른 포트를 선택하세요. 포트 확인과 실제 시작 사이에 다른 앱이 들어올 수 있어 충돌 검사는 실행 성공 보장이 아닙니다.

앱은 포트를 확보한 뒤 작업 복구·Slack 수신을 시작합니다. 종료는 .\Stop.ps1이며 데모는 .\Stop.ps1 -Port 8767입니다. 스크립트와 감독은 프로젝트·실행 인스턴스의 파일에 종료를 요청하고 고정 포트에 종료 HTTP를 보내지 않습니다. 실행 기록이 없으면 다른 앱을 추측해 종료하지 않습니다. 종료 요청 저장은 종료 완료 확인과 다르며 진행 중인 단계의 정리를 기다려 주세요.

runtime/app-포트.json은 모델·VM 설치 파일이 아닌 실행 기록입니다. 남은 기록만으로 프로세스가 살아 있다고 판단하지 않습니다. 예전 코드로 이미 실행 중인 감독에는 변경이 즉시 반영되지 않으므로 정상 종료 후 다시 시작해야 합니다.

1차 테스트 범위

팀 구성 → 데모 작업 등록 → 담당자별 대화 → 결과 확인 순서로 체험하세요. 데모는 지정된 샘플을 사용합니다. 실제 AI 작업은 로컬 모델 모드를 선택합니다.

VM 실제 화면 조작과 Slack 송수신, 외부 엔진 연결은 별도 검증이 필요합니다. 저장된 팀 설정이 손상된 작업은 원래 대화만 읽고 내보낼 수 있으며 임의의 담당자로 다시 실행하지 않습니다.
