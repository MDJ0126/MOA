데이터와 저장 위치

모델 추론과 작업 기록은 이 PC에서 처리합니다. Slack을 연결하면 지시·진행 상황·보고 내용은 Slack 서비스를 거칩니다.

토큰 보호

설정 화면은 저장된 토큰을 다시 보여주지 않습니다. 입력란을 비워 두면 기존 토큰을 유지합니다. 변경할 때만 새 토큰을 입력하세요. ‘연결 끄기’는 전송과 수신을 중지하고 토큰은 보존합니다.

결과물 ZIP은 작업 파일·보고서와 사용한 경우 VM 화면 기록을 포함합니다. 시스템의 Slack 토큰 저장소와 모델 서버 인증 키 파일은 자동으로 포함하지 않습니다.

로컬 주소

화면과 모델 서버는 loopback 주소에서만 수신합니다. 같은 네트워크의 다른 기기나 휴대폰에서 이 PC의 localhost 주소로 직접 접속할 수는 없습니다. Slack 메시지는 사용할 수 있지만 파일 다운로드를 위한 외부 공개는 구성하지 않았습니다.

파일 도구와 코드 실행

파일 도구는 작업 폴더 밖 경로를 차단합니다. 하지만 Python 테스트는 현재 사용자 권한으로 실행되며 OS 보안 샌드박스가 아닙니다. 역할별 기록 분리는 별도 Windows 계정이나 VM 격리를 뜻하지 않습니다.

백업과 이동

앱을 정상 종료한 뒤 필요한 data 기록과 결과물을 백업하세요. 토큰은 다른 사용자·PC에서 복원할 수 없을 수 있으므로 다시 입력하는 편이 적절합니다. 모델 파일은 공식 출처에서 다시 받을 수 있습니다.

VM 화면 기록

공유 VM 작업은 단계 전후 화면을 작업 폴더에 PNG로 저장하고 결과 ZIP에 포함합니다. 게스트 화면의 작업 내용과 입력된 정보가 보일 수 있으므로 보고서·ZIP을 공유하기 전에 화면 파일도 검토하세요. VM 화면에는 호스트 PC 화면을 캡처하지 않습니다.

Slack 토큰 저장과 복구

새 토큰은 Windows 사용자 DPAPI 암호문으로 데이터베이스에 저장하며 설정과 함께 한 번에 커밋합니다. 기존 slack.secrets 파일은 읽기 호환과 백업을 위해 보존합니다. 다른 Windows 계정에서 토큰을 읽지 못해도 설정 화면을 열 수 있습니다. 복구 안내의 새 토큰으로 교체를 선택하고 필요한 모든 토큰을 입력한 뒤 저장하면 새 계정의 암호문으로 교체합니다. 연결 확인만으로 설정을 바꾸지는 않습니다.
