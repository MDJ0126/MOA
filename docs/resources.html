작업 전에 준비 목록 확인

워크스페이스에서 할 일을 적고 필요한 프로그램·스킬 미리 보기를 누르세요. 작업 내용의 키워드로 후보를 보여 줍니다. 추천 자체가 필수 설치를 의미하지는 않습니다. Slack 협업 업무는 실제 VM 기준으로 준비 여부를 별도 확인합니다.

프로그램 설치

프로그램 탭에서 개별 설치 또는 여러 항목을 선택한 뒤 선택한 프로그램 설치를 누르세요. 처음에는 자동 준비 설정에서 설치 조건을 확인해 저장합니다. Windows WinGet의 공식 등록 ID로 사용자 범위 설치를 요청하며, 관리자 권한·자동 재부팅을 요청하지 않습니다. 사용자 범위 설치가 지원되지 않으면 실패 기록과 공식 사이트를 확인하세요.

설치 후에는 Windows 설치 기록이나 실행 파일 경로를 다시 검사합니다. 설치 명령이 성공을 반환해도 설치 근거가 없으면 완료로 처리하지 않습니다. 설치 목록 새로 확인으로 상태를 갱신할 수 있습니다. 주요 프로그램 목록은 Windows 설치 레지스트리 기준이며 모든 포터블 프로그램까지 포함하지는 않습니다.

실제 VM의 프로그램

PC에 설치한 프로그램은 VM에 자동 설치되지 않습니다. VM 프로그램 목록은 VM 작업 중 실제 command -v 결과로 확인합니다. VM 설치 예약은 다음 VM 업무가 사용권을 얻었을 때 실행합니다. 현재 번들 Tiny Core VM은 등록된 Python·Git 확장 패키지만 지원합니다. 네트워크가 꺼져 있으면 준비 필요로 표시하며 임의로 켜지 않습니다. VM 네트워크 설정을 바꾸었다면 VM을 재시작하고 현재 설정으로 새 작업을 등록하세요.

스킬 추가와 팀원 배정

스킬 탭에서 기본 제공 스킬을 추가하거나 내 스킬 추가로 이름·짧은 설명·지침을 작성하세요. Markdown 파일에서 지침을 읽어올 수도 있습니다. 사용할 팀원을 선택하지 않으면 모든 팀원이 사용합니다. 스킬은 지침 묶음이며 그 자체로 인터넷 검색·이미지 인식·프로그램 실행 도구를 새로 제공하지 않습니다.

봇이 필요할 때 자동으로 준비

봇 자동 준비 설정에서 프로그램 자동 설치와 허용 목록을 저장하세요. 프로그램은 허용 목록과 설치 조건 확인이 모두 충족되어야 합니다. 스킬은 등록된 항목만 요청할 수 있으며 자동 추가 설정과 팀원 배정을 확인합니다. 준비가 불가능하면 작업을 보류하고 이유를 기록합니다. Slack 협업 업무라면 사용자에게 준비 필요 메시지도 전달합니다. 실패·중단 설치를 몰래 반복하지 않으며 기록을 확인한 뒤 재시도할 수 있습니다.

전역·봇별 지시 사항

지시 사항 탭의 전역 지침은 모든 팀원에게, 봇별 지침은 선택한 팀원에게 전달됩니다. 저장한 지침과 활성 스킬은 새 작업에 반영됩니다. 진행 중 작업에는 접수 당시 내용이 유지됩니다. 봇이 작업 중 새로 요청한 스킬도 요청 당시 내용을 기록해 이후 편집과 분리합니다.
