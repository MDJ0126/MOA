# 프롬프트 첨삭과 역할 관리

워크스페이스에서 원문을 입력하고 **프롬프트 첨삭 봇**을 펼치세요. 여섯 항목은 선택 입력이며, 실제 AI 모드는 설정된 모델로 원문을 정리합니다. 데모는 모델 없이 입력을 구조화합니다. 미확인 항목은 임의로 확정하지 않고 표시합니다. 첨삭안을 직접 수정한 뒤 **이 내용으로 작업 입력 → 팀에 맡기기** 순서로 실행하세요.

**팀 설정 → 전문 역할·추가 지침**에서 교육과정 설계자, 설문 분석가 등 전문 역할을 자유롭게 지정하세요. 계획·개발·검증·보고 버튼은 실제 실행 단계를 배정하며, 전문 역할과 추가 지침은 해당 팀원의 모델 입력에 전달됩니다. 여러 팀원이 같은 단계를 맡으면 기존 부하 기준으로 담당자를 선택합니다. 실행 단계는 현재 네 단계이며 로컬 모델을 순차 사용합니다. 새 역할 저장은 새 작업부터 적용하고 기존 작업은 등록 당시 역할을 보존합니다.

전문 역할 이름만으로 외부 도구가 추가되지는 않습니다. 슬라이드·설문 서비스 연결 등은 별도 구현이 필요합니다.
