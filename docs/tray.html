시스템 트레이로 실행하기

프로젝트 폴더의 모아 실행.vbs를 더블클릭하세요. 콘솔 창 없이 우측 하단 알림 영역에 MOA 아이콘이 표시됩니다. 숨겨진 아이콘 목록에 들어갈 수도 있습니다.

  • 아이콘 더블클릭 또는 우클릭 → 모아 열기: MOA 워크스페이스와 Slack 메신저 탭이 있는 전용 창을 엽니다. 탭을 오가도 화면은 유지됩니다.
  • 우클릭 → 일시 중지 / 계속 실행: 업무 처리를 제어합니다.
  • 우클릭 → 모아 종료: 진행 중 단계의 정리를 요청하고 트레이와 백그라운드 앱을 종료합니다.

관리 창을 닫아도 백그라운드 업무는 계속됩니다. 중복 실행하면 기존 트레이를 유지합니다. Windows 시작 시 자동 실행은 등록하지 않습니다.

PowerShell에서는 .\Start.ps1 또는 .\Start-Tray.ps1을 사용하세요. 기존 콘솔 실행은 .\Start.ps1 -Console로 유지됩니다. 트레이 실행에는 현재 설치된 PowerShell 7과 Windows Forms를 사용합니다.

Slack 메신저

창 상단의 Slack 메신저 탭을 선택하세요. 공식 Slack 웹 화면을 같은 프로그램 안에서 사용합니다. 처음 한 번은 Slack 로그인이 필요합니다. Chrome·Edge·Slack 앱의 로그인과 별도로 관리되며, 로그인 정보는 이 PC의 전용 프로필에 보관됩니다. MOA의 봇 연결 설정과 사용자의 Slack 로그인은 별개입니다.

창을 닫으면 트레이에 남고, 트레이를 다시 열면 같은 창으로 돌아옵니다. MOA 종료를 선택하면 전용 창도 종료합니다. 최초 실행 시 Microsoft 공식 NuGet에서 WebView2 구성 요소를 준비합니다. 일반 브라우저에서 연 MOA 페이지에는 데스크톱 상단 탭이 없습니다.

작업 완료 알림

완료 알림은 기본으로 켜져 있습니다. 팀 설정 → 작업 환경 → 작업 완료 알림 → Windows 알림 받기에서 켜고 끌 수 있습니다. 테스트 알림 보내기로 표시를 확인하세요. 관리 창을 닫아도 트레이가 실행 중이면 알림을 받으며, 알림을 클릭하면 MOA를 엽니다.
