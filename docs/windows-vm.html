Windows VM에서 작업하기

모아가 실행되는 PC와 봇이 작업하는 VM은 별개입니다. 작업 환경에서 Windows · 공유 VM을 선택하면 다른 OS로 대신 실행하지 않습니다.

1. Windows 설치 준비

Microsoft에서 사용 권한이 있는 Windows 설치 ISO를 준비해 프로젝트의 runtime/vm-downloads 안에 넣어 주세요. 설정 → 작업 환경에서 Windows VM을 선택하고 ‘빈 디스크 만들기’로 64GB 디스크를 준비합니다. RAM은 최소 4GB, 개발 도구는 8GB 이상을 권장 시작값으로 제공합니다. 실제 여유 메모리를 먼저 확인하세요.

설치 ISO와 영구 디스크 경로를 저장한 뒤 VM을 시작합니다. 화면 캡처·키 입력으로 OS를 설치하고 약관·계정 로그인·정품 인증은 직접 완료하세요. 설치 후 ISO 경로를 비우면 디스크로 부팅합니다. Windows 11의 TPM·UEFI/Secure Boot 자동 준비는 현재 미지원입니다. 설치 요건을 우회하지 않습니다.

2. 명령 연결

Windows VM 안에 서명된 virtio-win 드라이버와 QEMU Guest Agent를 공식 배포 경로에서 설치합니다. virtio serial 드라이버와 QEMU Guest Agent 서비스가 필요합니다. 모아는 이 채널을 localhost로만 열며, 명령은 Windows VM의 PowerShell에서 실행됩니다. 서비스 계정으로 실행되므로 로그인된 데스크톱과 다른 세션일 수 있습니다. GUI 조작·Unity/Unreal 플레이 모드가 연결됐다는 뜻은 아닙니다.

‘Windows 명령 연결 확인’을 눌러 실제 OS 응답을 확인하세요. 연결 실패 시 작업을 현재 PC나 Linux로 옮겨 실행하지 않습니다.

3. 실행 환경과 설치

저장한 실행 환경은 새 업무에 적용됩니다. 상단에 선택 환경, 작업 환경에 가동 VM과 실제 진행 업무의 위치를 표시합니다. 도구와 스킬의 프로그램 카드는 선택한 환경의 설치 지원 여부를 표시합니다. Windows VM 자동 설치는 WinGet·네트워크·사용자 설치 조건 확인이 필요합니다. Linux VM은 Tiny Core 확장 패키지만 지원합니다. 원격 PC 자동 설치는 미지원입니다.

Unity·Unreal은 로그인·라이선스를 직접 확인해야 합니다. GPU·GUI·엔진 실행 검증은 별도이며, 설치 완료와 게임 실행 성공을 동일하게 표시하지 않습니다. Windows 자체 라이선스가 무조건 무료인 것은 아닙니다.
