MOA에서 AI 팀원 봇 추가하기

Slack은 봇끼리의 DM을 허용하지 않습니다. 팀원끼리는 업무 채널, 사용자와는 각자의 DM을 사용합니다.

팀원마다 사람 이름과 프로필을 가진 Slack 봇을 연결합니다. 토큰 복사나 별도 앱 수동 설정은 필요하지 않습니다. 처음 한 번 Slack에서 인증한 다음, MOA의 봇 추가 버튼으로 진행하세요.

1. Slack에 가입하고 MOA 열기

아직 계정이 없으면 Slack 시작하기에서 가입·워크스페이스 생성을 진행하세요. 그다음 MOA · 팀원 봇 연결을 여세요. 데스크톱 Slack 설치는 선택입니다.

2. 처음 한 번 Slack 인증

일반 팀원 설정에서 이름·사진을 정하고, Slack 연결 화면에서 해당 팀원 오른쪽의 연결하기를 누르세요. 최초 인증 안내가 열리고, 승인하면 선택한 팀원 봇 등록을 자동으로 이어갑니다.

  1. MOA에서 Slack 인증 시작을 누르세요. 공식 Slack 연결 도구는 MOA가 준비합니다.
  2. 표시되는 /slackauthticket … 명령을 ‘인증 명령 복사’로 복사하고 Slack의 아무 대화 입력창에 붙여 넣어 전송하세요. 이 명령은 최초 권한 승인을 위한 일회용 인증입니다.
  3. Slack이 표시하는 권한 내용을 읽고 직접 승인하세요. 워크스페이스 정책에 따라 관리자 승인이 필요할 수 있습니다.
  4. Slack에 나타난 확인 코드를 MOA의 Slack 확인 코드에 입력하고 인증 완료를 누르세요. 이것은 봇 토큰이 아니라 일회용 로그인 확인 코드입니다.

인증을 마치면 봇마다 토큰을 찾거나 복사하지 않아도 됩니다. 인증 명령과 확인 코드는 다른 사람에게 공유하지 마세요.

3. 팀원별로 연결하기

지우: 계획·VM 작업 담당 / 서연: 검증·보고 담당. 예시 이름이며 팀 설정에서 자유롭게 바꾸실 수 있습니다.

  1. 팀원 설정에서 이름과 프로필 사진을 저장하세요. PNG·JPEG·WebP 사진을 선택하면 모아가 정사각형으로 맞춥니다.
  2. Slack 연결 화면에는 팀원마다 한 줄씩 표시됩니다. 오른쪽 연결하기를 누르면 봇을 자동 준비하고 연결됨으로 바뀝니다.
  3. 이후 이름·사진은 팀원 설정에서만 바꾸세요. 연결된 Slack 프로필에도 자동 반영됩니다.
  4. 모든 팀원이 연결되면 업무 채널 참여·Socket Mode를 검사하고 협업 연결을 켭니다.

기본 업무 채널 #moa-team은 자동 준비합니다. 기존 보고 채널을 지정했다면 그 채널을 사용합니다. 비공개 채널은 직접 봇 초대가 필요할 수 있습니다.

‘You’re creating apps too quickly’가 표시되면 잠시 기다린 뒤 같은 팀원에서 다시 시도해 주세요.

4. 사무실 대화와 Slack 메신저

대시보드의 캐릭터를 누르면 모아 안에서 직접 대화합니다. 이 기록은 Slack에 자동 전송되지 않습니다. 실제 작업은 업무로 맡기기를 눌러 실행하세요. Slack에서는 각 팀원에게 DM으로 연락합니다.

Slack에서 지우의 프로필을 열고 메시지를 누르세요. “VM에서 ready.txt를 만들고 서연에게 화면과 결과를 보내 검증받아 주세요.”처럼 요청하시면 됩니다.

지우 VM 작업 → 업무 채널에서 서연에게 메시지·이미지 전달 → 서연 수신 확인 → VM 검증 → 결과 보고 순서입니다. 수정이 필요하면 서연이 업무 채널에서 지우에게 요청합니다. 팀원끼리는 업무 채널에서 대화하며, 사용자는 각 팀원의 프로필을 열어 개별 DM으로 소통할 수 있습니다.

실제 파일 작업은 MOA가 실행하는 Linux VM 안에서 수행합니다. 현재 텍스트 모델은 이미지를 전송·수신하되 픽셀을 이해하지 않으며, 검증은 명령 출력·종료 코드·실제 파일을 근거로 합니다.

기존에 만든 봇을 재사용하거나 수동으로 연결하기

이미 만든 봇은 삭제할 필요가 없습니다. 이름·사진을 바꿔 사용할 수 있습니다. 자동 추가는 MOA가 관리하는 새 봇을 등록하므로 기존 봇을 그대로 쓰려면 아래 수동 연결 절차를 선택하세요.

모아의 팀 설정에서 이름과 역할을 정하세요. 팀원마다 별도 봇 하나가 필요합니다. 공유 팀 봇은 이번 구성에 사용하지 않습니다.

이미 예전 이름으로 만든 봇이 있다면

이 안내에서 예전 역할 이름을 제거했으며, Slack에 이미 등록한 계정을 자동 삭제하지는 않습니다.

3. 각 팀원의 이름·프로필 사진 지정

  1. Your Apps에서 팀원 봇을 선택하세요.
  2. Basic Information → Display Information에서 사람 이름과 설명을 입력하고 App icon & Preview에서 해당 팀원의 사진 또는 아바타를 올려 저장하세요. 각 팀원에게 서로 다른 이미지를 사용하면 구분하기 쉽습니다.
  3. App Home에서 봇 이름을 확인하세요. 아래의 Messages Tab과 Allow users to send Slash commands and messages from the messages tab 옵션이 켜져 있어야 사용자가 DM을 보낼 수 있습니다. 준비된 설정에는 메시지 탭이 포함되어 있습니다.

이름은 팀원의 정체성이고, 계획·개발·검증은 맡은 역할입니다. 프로필에 ‘AI 팀원’이라고 적어 두시면 사람 계정과 구분할 수 있습니다.

4. 각 봇의 토큰 두 개 발급

토큰은 모아가 그 팀원 봇으로 Slack에 접속할 때 쓰는 비밀 열쇠입니다. 직접 이름을 지어 입력하는 값이 아니라 Slack이 발급한 값을 복사합니다. 팀원마다 아래 두 개를 발급받으세요.

  • Bot User OAuth Token (xoxb-): 해당 팀원 이름으로 메시지·이미지를 주고받는 열쇠입니다.
  • App-Level Token (xapp-): 새 DM을 실시간으로 수신하는 연결용 열쇠입니다. 여기에 connections:write 권한을 지정합니다.
  1. OAuth & Permissions → Install to Workspace를 눌러 설치를 승인하세요. 이미 설치했다면 새 im:write 권한이 반영되도록 Reinstall to Workspace를 진행하세요.
  2. 같은 화면의 Bot User OAuth Token(xoxb-)을 복사하세요.
  3. Basic Information → App-Level Tokens → Generate Token and Scopes에서 토큰 이름을 입력하고 connections:write를 추가한 뒤 생성하세요. xapp- 토큰을 복사하세요.
  4. Socket Mode가 켜져 있는지, Event Subscriptions → Subscribe to bot events에 message.im이 포함되어 있는지 확인하세요. 준비된 설정에 포함되어 있습니다.
  5. 다른 팀원 봇에서도 같은 절차를 반복하세요. 서로 다른 두 봇의 토큰이어야 합니다.

토큰은 채팅에 보내지 말고 다음 단계의 이 PC 설정 화면에만 입력하세요.

5. 모아에서 각 팀원과 봇 연결

팀원 봇 연결 화면 열기

  1. Slack 업무 채널에 두 봇을 초대하세요. 채널 이름 → 채널 정보에서 채널 ID를 복사해 ‘보고 채널 ID’에 입력하세요.
  2. Slack에서 내 프로필 → 더 보기 → 멤버 ID 복사로 ID를 복사하고 ‘지시를 허용할 내 Slack 멤버 ID’에 입력하세요.
  3. 지우 연결의 담당 팀원을 지우로 선택하고 지우의 xoxb-, xapp-를 입력하세요. 서연도 별도 연결로 입력하세요. 연결 행이 없으면 팀원 봇 추가 +를 누르세요.
  4. Slack에서 팀원 협업·이미지 공유·실제 VM 작업 진행과 팀원끼리 업무 채널에서 대화·이미지로 업무 주고받기를 모두 켜세요.
  5. 연결 확인은 인증·채널·Socket Mode와 채널 참여와 소켓 연결를 검사합니다. 메시지는 보내지 않지만 DM 대화방은 생성될 수 있습니다. 성공하면 저장하고 연결을 누르세요.
자동 연결이 막힐 때
  • 인증 만료: Slack 인증 시작을 다시 누르고 새 확인 코드로 승인하세요.
  • 관리자 승인 필요: 워크스페이스 관리자의 승인을 받은 뒤 같은 팀원에서 다시 시도하세요.
  • 생성 간격 제한: 잠시 기다린 뒤 다시 시도하세요. 같은 MOA 팀원 프로젝트를 재사용합니다.
  • 채널 수신 미확인: 다음 VM 작업을 보류합니다. MOA의 연결 오류를 확인해 주세요. 채널 대화를 DM 성공으로 대신 처리하지 않습니다.
  • 백업 복원: CLI 로그인 정보는 백업에서 제외합니다. 복원한 PC에서는 최초 Slack 인증을 다시 진행하세요.
